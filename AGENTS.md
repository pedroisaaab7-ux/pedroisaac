# AGENTS

## Regras LGPD
- **Não** registrar em logs/console CPF, nome completo ou número de processo.
- **Mascarar CPF** na UI (ex.: ***.***.***-**).
- **Não** commitar secrets (tokens, senhas, chaves, `DATABASE_URL` real).

## Padrões de projeto
- Manter lint, build e testes mínimos funcionando.
- Atualizar `README.md` sempre que mudar comandos essenciais.

## Convenções de domínio
- **Processo**: representa o caso PASEP.
- **Fases**: etapas do processo (planejado para evolução futura).
- **Notas**: registros textuais associados ao processo.
